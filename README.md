# **D**ocker **S**imple **D**rupal
Easy way to deploy Drupal project in few steps. Take 🍸 and let the magic happen!

### Prerequisites
[Docker](https://docs.docker.com/engine/installation) and [Docker Compose](https://docs.docker.com/compose/install)

> **Windows users:** run the install script from WSL or Git Bash.

### Installation
1. Clone the directory `git clone https://github.com/alan-ps/dsd`
2. Build containers `docker compose up -d`
3. Run installation `./.build/install.sh scratch`
